如果AI陪伴可以离开手机屏幕？

便携式语音陪伴硬件

我做了一款面向虚拟陪伴用户的便携硬件，可以实时语音对话，出门也能随身携带。我负责用户访谈、原型设计、硬件选型、电路焊接和原型测试。

产品简介

我希望用户在出门或睡前也能直接和喜欢的角色对话。设备基于小智系统，通过 API 获取对话回复，再由设备播放云端生成的语音。写入角色 Prompt 后，设备就能用设定好的角色来回应。

研究目标和招募对象

  • 理解角色互动习惯
  • 识别语音陪伴期待
  • 比较记忆和实时互动吸引力
  • 探索载体与风险

招募条件

近一年体验过至少两款乙女游戏；有相关付费经历；对虚拟角色情感互动持积极态度；有智能音箱或AI对话产品使用经验。

研究方式

我独立设计访谈提纲并访谈了 20 位目标用户。提纲按约 30 分钟设计，访谈后用 NVivo 进行开放编码和主题提炼。

访谈具体问什么

A 背景与行为

平时玩哪些乙女游戏？偏好角色的什么特征？什么时候互动？这些体验满足什么需求？

B 交互核心要素

理想的AI性格是什么？偏好怎样的声音？希望它记住什么？希望记忆在什么时候被主动提起？

C 场景与产品边界

睡前、通勤或工作间隙怎么用？理想载体是什么？哪些功能值得付费？担心出戏、尴尬或失去控制吗？

部分问题提供概念提示，旨在收集探索性反馈。上市后的购买意愿需另行验证。

从访谈到设计

便携语音交互

访谈里，用户提到睡前和出门时希望随时开口交流。我把便携和实时语音作为硬件的重点，完成了硬件选型、电路焊接与原型设计。

角色设定与多轮对话

用户希望熟悉的角色能保持自己的说话方式。我用 Prompt 配置角色性格、语言风格、多轮对话逻辑和情感识别策略。

后续探索 · 记忆与周边载体

访谈也提出了自然调用长期记忆、把语音模块放入熟悉周边的需求，这两点可以继续验证。

用户测试

硬件制作完成后，我招募目标用户进行原型可用性测试，观察在具体场景中，用户能否顺畅开始语音对话，以及设备是否能提供所期待的情感回应。
